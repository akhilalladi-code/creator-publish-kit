# Contributing\n\nThanks for helping improve Creator Publish Kit. Keep changes focused, maintain the local-first privacy model, and avoid adding dependencies without a clear need.\n\n## Development\n- Use Node.js 18 or newer.\n- Run `npm run validate` before opening a pull request.\n- Add tests for changes to parsing, validation or export behavior.\n- Keep accessibility in mind: labels, keyboard access, visible focus and useful status messages.\n\n## Pull requests\nExplain the user problem, summarize the change, list validation performed, and note any privacy or compatibility implications.\n
