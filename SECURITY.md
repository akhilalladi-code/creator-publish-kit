# Security policy\n\n## Reporting a vulnerability\n\nPlease do not publish exploitable details in a public issue. Contact the repository maintainer privately through the contact options on the GitHub profile and include reproduction steps, impact and affected versions.\n\n## Data handling\n\nThe application has no server component. Drafts are stored in browser localStorage. Thumbnail files are read locally by the browser for preview and dimension checks; they are not transmitted by this application. Avoid placing secrets or sensitive client information in exported files.\n
